    API를 제공하는 호스트 (이름 또는 IP)입니다.
    호스트는 scheme이나 sub-paths는 포함하지 않습니다.
    그리고 포트를 포함 할 수 있습니다. 호스트가 포함되지 않은 경우 문서를 제공하는 호스트를 사용해야 합니다 (포트 포함).

    기본경로
    호스트와 관련된 API가 제공되는 기본 경로입니다. 기본경로는 슬래시 (/)로 시작해야 합니다.
    기본 경로

    기본경로 URL은 http : // 또는 https : //로 시작해야 합니다. 예 : http://KT.com

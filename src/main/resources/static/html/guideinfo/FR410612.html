Python Flask 설치가이드

1. 서버 SDK에서 Python Flask의 다운로드 버튼을 클릭하십시오.

2. 다운받은 python-flask-server-generated.zip 파일을 원하는 위치에 압축을 푸십시오.

3. 소스의 폴더 구조를 확인하십시오.

4. 다음과 같은 방법으로 소스코드를 수정하십시오.

  1. ① ./swagger-server/__main.__.py 파일의 port 확인 및 수정
  2. ② ./controllers 디렉토리 하위의 py 소스내 HTTP Operation별 Method에 비즈니스 로직 추가

5. API 호출 및 테스트를 진행 하십시오.

  1. ① 실행 환경 : Python 3.5.2+ (./python-flask-server/README.md 참고)
  2. ② ./python-flask-server에서
    • - 필요라이브러리 설치 : pip3 install –r requirements.txt
    • - 실행 : python3 –m swagger_server
  3. ③ 테스트 : http://localhost:8080/v1/ui/ 접속

    ex) curl

    curl -X POST "http://localhost/v1/path" -H "accept: application/xml" -H "Content-Type: application/json" -d
    "{ \"id\": 0, \"category\": { \"id\": 0, \"name\": \"string\" }, \"name\": \"doggie\",
    \"photoUrls\": [ \"string\" ], \"tags\": [ { \"id\": 0, \"name\": \"string\" } ], \"status\":
    \"available\"}“
    ex) postman : body에 raw를 선택하여 json 데이터를 입력하여 테스트

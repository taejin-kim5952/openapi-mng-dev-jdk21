Spring 설치가이드

1. 서버 SDK에서 Spring의 다운로드 버튼을 클릭하십시오.

2. 다운받은 spring-server-generated.zip 파일을 원하는 위치에 압축을 푸십시오.

3. 소스의 폴더 구조를 확인하십시오.

4. 다음과 같은 방법으로 소스코드를 수정하십시오.

  1. ① Api 디렉토리 하위의 PATH 이름별 XXXXXXController.java 열기
  2. ② Controller java 소스내 HTTP Operation별 Method에 비즈니스 로직 추가

5. API 호출 및 테스트를 진행 하십시오.

  1. ① Application.properties의 Port 확인 (./spring-server/README.md 참고)
  2. ② SpringBoot 프로젝트 실행
  3. ③ Curl 또는 Postman을 이용하여 API 호출 및 테스트

    ex) curl

    curl -X POST "http://localhost/v1/path" -H "accept: application/xml" -H "Content-Type: application/json"
    -d "{ \"id\": 0, \"category\": { \"id\": 0, \"name\": \"string\" }, \"name\": \"doggie\",
    \"photoUrls\": [ \"string\" ], \"tags\": [ { \"id\": 0, \"name\": \"string\" } ], \"status\":
    \"available\"}“
    ex) postman : body에 raw를 선택하여 json 데이터를 입력하여 테스트

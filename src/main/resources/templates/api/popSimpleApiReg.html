    카테고리 설명
    • API에 대한 기본 정보를 등록합니다.
    • API의 Path정보는 시스템명, 버전 그리고 입력하신 API명이 조합되어 자동 생성 됩니다.
    • 입력하신 API설명은 사용자가 이용하는 이용가이드에 노출되기 때문에 자세하게 작성 부탁드립니다.
    • API ID는 API의 고유한 ID이며 중복을 방지하기 위하여 자동 생성됩니다.

    • API 사용을 위한 Request Body의 파라미터명, 설명, TEST DATA를 입력합니다.

    • 입력하신 DATA는 request Obeject에 data이며 다른 common규격의 API를 참고하시기 바랍니다.

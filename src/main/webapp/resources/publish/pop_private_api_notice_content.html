KOS API등록 주의 사항

API등록 후 자동 배포된 API는 API Link의 이용가이드(연동 규격서)에 노출 됩니다. 때문에 사용자가 필요하지 않은 정보는 "CP미노출"로 체크 하시기 바랍니다.

1. KOS API Request header 값은 API Link G/W와 KOS연동 시 사전에 정의된 값으로 G/W에서 자동 세팅되어 전송되기 때문에 특정 값(chnlType, userId, orgId, srcId)을 제외하고 사용자는 입력 하지 않습니다. 때문에 "CP미노출"로 체크 하셔야 합니다.(chnlType, userId, orgId, srcId는 미체크)

2. KOS API Request body 값은 API Link G/W와 KOS연동 시 사전에 정의된 값으로 G/W에서 자동 세팅되어 전송되기 때문에 사용자는 입력 하지 않습니다. 때문에 "CP미노출"로 체크 하셔야 합니다.

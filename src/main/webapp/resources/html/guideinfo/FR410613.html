Php Symfony 설치가이드

1. 서버 SDK에서 Php Symfony의 다운로드 버튼을 클릭하십시오.

2. 다운받은 php-symfony-server-generated.zip 파일을 원하는 위치에 압축을 푸십시오.

3. 소스의 폴더 구조를 확인하십시오.

4. 다음과 같은 방법으로 소스코드를 수정하십시오.

  1. ① ./SymfonyBundle-php/README.md의 “Getting Started” 절차에 따라 php 파일 및 테스트

5. API 호출 및 테스트를 진행 하십시오.

  1. ① 실행 환경 : PHP 5.4.0 and later (./php-symfony-server/README.md참고)
  2. ② ./SymfonyBundle-php/README.md의 “Installation & Usage”에 따라 추가 설치
  3. ③ 테스트 : README.md의 “Tests”에 따라 실행
